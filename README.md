# meta-ronetix

Yocto BSP layer for the Ronetix i.MX SoMs, for the FSL Community BSP
(Yocto Project wrynose).

## Machines

| Machine                 | SoM                    | SoC      | U-Boot defconfig                |
|-------------------------|------------------------|----------|---------------------------------|
| `imx8mm-compact-2gb-cm` | i.MX8MM-COMPACT-2GB-CM | i.MX8MM  | `imx8mm_compact_2gb_cm_defconfig` |
| `imx8mm-compact-cm`     | i.MX8MM-COMPACT-CM     | i.MX8MM  | `imx8mm_compact_cm_defconfig`   |
| `imx8mm-cm`             | i.MX8MM-CM             | i.MX8MM  | `imx8mm_cm_defconfig` (1)       |
| `imx8mn-compact-cm`     | i.MX8MN-COMPACT-CM     | i.MX8MN  | `imx8mn_compact_cm_defconfig`   |
| `imx8mn-cm`             | i.MX8MN-CM             | i.MX8MN  | `imx8mn_cm_defconfig` (1)       |
| `imx8mq-cm`             | i.MX8MQ-CM             | i.MX8MQ  | `imx8mq_cm_defconfig`           |
| `imx7-cm`               | i.MX7-CM               | i.MX7D   | `imx7_cm_defconfig`             |

(1) not yet ported to U-Boot `ronetix/v2025.01`

The machines use the mainline BSP of meta-freescale:

- U-Boot: `u-boot-ronetix`, from https://github.com/ronetix/u-boot,
  branch `ronetix/v2025.01`. On the i.MX8M SoMs U-Boot builds the boot
  container `flash.bin` (SPL, DDR firmware, BL31 and U-Boot).
- Linux: `linux-ronetix`, from https://github.com/ronetix/linux,
  branch `ronetix/6.12.x+fslc`, configured with `defconfig` (i.MX8M) or
  `imx_v6_v7_defconfig` (i.MX7) plus the fragments in
  `recipes-kernel/linux/linux-ronetix`.
- The i.MX8M SoMs boot Linux with `extlinux/extlinux.conf`, generated by
  the U-Boot recipe (`UBOOT_EXTLINUX`). The i.MX7-CM boots `zImage` and
  `imx7-cm.dtb` from the boot partition with U-Boot's own boot command.

## Development images

The images for the Ronetix machines are development images: root logs in
without password on the console and over SSH (image features
`allow-empty-password allow-root-login empty-root-password`, see
`conf/machine/include/ronetix-common.inc`). For production images add to
`conf/local.conf`:

```
RONETIX_DEV_IMAGE_FEATURES = ""
```

- meta-openembedded: meta-oe, meta-multimedia, meta-python, meta-networking
- meta-freescale, meta-freescale-3rdparty, meta-freescale-distro

## Build

With the Ronetix BSP manifest the layers and the build configuration are
set up by `setup-environment`:

```
repo init -u https://github.com/ronetix/bsp-repo -b wrynose
repo sync
MACHINE=imx8mm-compact-2gb-cm DISTRO=fslc-wayland source ./setup-environment build
```

With the FSL Community BSP manifest
(https://github.com/Freescale/fsl-community-bsp-platform) add meta-networking
and meta-ronetix to `conf/bblayers.conf`:

```
  ${BSPDIR}/sources/meta-openembedded/meta-networking \
  ${BSPDIR}/sources/meta-ronetix \
```

and enable the PR server in `conf/local.conf`, so the package versions of
the git based recipes u-boot-ronetix and linux-ronetix increase with every
new commit (otherwise the QA check version-going-backwards may fail):

```
PRSERV_HOST = "localhost:0"
```

The DDR training firmware of the i.MX8M SoMs is distributed under the
NXP EULA, which must be accepted in `conf/local.conf`
(`ACCEPT_FSL_EULA = "1"`) after reading `sources/meta-freescale/EULA`.

```
bitbake core-image-minimal
bitbake fsl-image-gui
```

The result `tmp/deploy/images/<machine>/<image>-<machine>.rootfs.wic.gz`
can be written to a SD card with bmaptool (using the `.wic.bmap` file next
to it) or with dd:

```
sudo bmaptool copy <image>-<machine>.rootfs.wic.gz /dev/sdX
zcat <image>-<machine>.rootfs.wic.gz | sudo dd of=/dev/sdX bs=1M conv=fsync
```
